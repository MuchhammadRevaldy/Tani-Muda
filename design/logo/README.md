# Logo Tani Muda (D-63)

- `logo_with_bg.jpg`, `no_bg.jpg`: render 3D sumber dari pemilik produk, untuk slide dan dokumen. Tidak dipakai di aplikasi (JPG tidak transparan dan terlalu besar).
- Aplikasi memakai SVG di `frontend/public/logo/`: `logo-tanda.svg` (tanda merek di latar terang), `logo-satu-warna.svg` (latar gelap, currentColor), `logo-ikon.svg` dan `logo-ikon-maskable.svg` (sumber favicon dan ikon PWA, dibuat ulang dengan `node frontend/scripts/buat-ikon.mjs`). Pratinjau: `docs/tema-baru/acuan/logo/pratinjau.png`.
